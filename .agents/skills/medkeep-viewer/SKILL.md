# MedKeep - 临床闭环聚类与看板运维 Skill (medkeep-viewer)

本 Skill 负责驱动 MedKeep 零依赖轻量 Python 看板，并管理临床事件流的高内聚展现。

---

## 核心职责

### 1. 服务生命周期管理
- 启动服务：`python3 server.py`（默认监听 `http://127.0.0.1:8765`）
- 特点：
  - 纯原生 Python 3 标准库（`http.server`, `urllib`, `json`），零外部 `pip` 依赖。
  - 内存占用 `< 20MB`。
  - 静态页面直接磁盘直读，改动 HTML/JS 刷新浏览器即生效。
- 端口占用应对：若 `8765` 被占用，自动通过 `--port` 参数切换至备用端口（如 `8766`）。

### 2. 临床事件流编排（Episodes 闭环）
- 依据临床逻辑，以**门诊病历（visit）**作为主干锚点。
- 将同日或跨天开具的检验（lab）、功能检查（exam）、影像报告（imaging）自动挂载至该就诊事件下，形成 `EP-{PERSON}-{SEQ}`。
- 无门诊病历的独立化验/影像，标记为 `created_by_agent: true` 的“辅助检查建档”。

### 3. 病情全景大类聚类（Conditions 纵向归拢）
- 将分散在不同年份、不同科室的同一系统慢性疾病或专科病痛，归拢至统一大类：
  - 呼吸专科（上呼吸道感染、咳嗽随访）
  - 消化系统（胃肠炎、消化道随访）
  - 心血管科（高血压、心率与血脂管理）
  - 健康体检（年度体检、综合健康评估）
  - 全科与综合门诊（日常门诊、慢病管理）
- 自动计算该病情跨度起止时间（`date_span`），累计就诊次数与关联单据总量。
