# MedKeep - 单据转换与规范命名 Skill (medkeep-archive)

本 Skill 强制执行 MedKeep 医疗原件物理归档的核心标准。

---

## 核心准则

### 1. 格式分级原则（单双页转 JPG vs 多页集合保留 PDF）
- **单页或双页临床报告单（化验单、检查单、门诊病历等）**：拆分为高保真 `.jpg`（300 DPI / 2400px+），通过 `-p1`、`-p2` 标记页码。
- **多页集合型长文档（如完整的年度体检报告 PDF 等）**：**严禁拆分为 JPG**！原样保留 `.pdf` 格式归档（如 `YYYYMMDD-checkup-general.pdf`）。
- **非病历文件过滤（保险合同/保单等）**：商业保险合同、电子保单、投保核保告知等非医疗诊断单据，**严禁录入病历库**。

### 2. V2.0 标准四段式命名规范
所有单据文件名必须且只能遵循以下规则：
```text
YYYYMMDD-{type}-{category}-pN.jpg  （单/双页报告单）
YYYYMMDD-checkup-general.pdf       （多页集合型体检报告）
```
- **第 1 段（日期）**：`YYYYMMDD`（以单据上打印的真实就诊/检查日期为准）。
- **第 2 段（单据类别 `type`）**：
  - `visit`：门诊病历、急诊病历、病程记录
  - `discharge`：出院记录、出院小结
  - `lab`：化验单、血液检测、尿检、便检、微生物培养
  - `exam`：功能检查（心电图、肺功能、听力测听、脑电图）
  - `imaging`：影像学（超声、CT、核磁 MRI、DR/X光、皮肤镜）
  - `rx`：独立处方笺、中药配药单
  - `checkup`：健康体检报告
- **第 3 段（临床主题 `category`）**：
  - `resp` 呼吸 / `ent` 耳鼻喉 / `gi` 消化肠道 / `derm` 皮肤 / `cv` 心血管 / `rheum` 风湿免疫 / `tcm` 中医 / `ped` 儿科 / `eye` 眼科 / `general` 综合
- **第 4 段（页码）**：`p1`, `p2`, `p3`...

### 3. 本地存储分发与画质前置质检
- 目标路径格式：`records/{person_id}/{year}/{filename}`
- 例如：`records/demo/2026/20260315-lab-cbc-p1.jpg`
- **方向自动正置**：若原图存在 90°/180°/270° 旋转横置，必须在归档时旋转正置，确保看板阅读体验。
- **清晰度阻断质检**：归档前必须逐张检视分辨率与文字可读性；若发现图片严重失焦、关键文字被遮挡或裁切不全，必须立即通知用户重新拍摄上传或人工补充，严禁直接归档模糊废片。

### 4. 重复/补拍单据的智能比对优选与统一压缩置换机制 (Deduplication & Replacement Protocol)

当用户重新拍摄或上传一批新照片时，若对应单据在归档目录中**已经存在**（同日同类型同主题），Agent 严禁无脑覆盖或直接丢弃，必须执行以下对比与压缩置换规范：

#### A. 四级质量与完整性对比阶梯（Priority Hierarchy）
1. **P0（最高优先级）：信息完整性（绝对不能缺失）**
   - **边缘完整度**：四角四边完整入画，医院抬头、就诊日期、患者姓名、化验项目右侧参考值/单位等无任何边缘裁切；
   - **遮挡物检测**：画面中无手指压按、胶带纸遮盖、药盒遮挡或严重折痕破坏关键正文字迹；
   - **多页完备性**：若旧档仅有 `p1`，新图补齐了完整双页（`p1` + `p2`），判定新图具有更高完整性。
2. **P1（核心指标）：清晰度与高清可读性（无重影拖影）**
   - **对焦精准锐利**：文字笔画与表格框线边缘锐利，无手抖造成的重影、虚化或运动模糊（Motion Blur）；
   - **细小手写字辨识**：微小印刷字、医生手写处方与增减剂量 100% 清晰可辨，无需推测字迹；
   - **有效主体分辨率**：在裁除背景杂物后，单据主体的实际物理像素充足。
3. **P2（重要指标）：光照质量与反光控制**
   - **无大面积强光反白**：热敏纸、光面化验单无白色反光斑块吞噬字迹；
   - **光照均匀**：无手机近拍投影、人影大面积遮蔽病历关键部位。
4. **P3（辅助指标）：拍摄视角平整度与几何形变**
   - **垂直正视拍摄**：垂直 90° 俯拍为佳，无严重梯形透视失真；
   - **纸张平展**：无波浪起伏折叠造成的视觉扭曲。

#### B. 比对决策与统一压缩落盘流水线 (Unified Compression Pipeline)
- **判定新图显著更优（更完整、更锐利、无遮挡）**：
  1. **采用新图置换**既有旧图；
  2. **统一标准压缩（强制执行）**：无论原拍摄图原始体积多大（如 10MB~20MB 的手机大图），**必须统一处理后再落盘**：
     - 方向自动正置（Auto-Orient）；
     - 长边等比缩放至 **2400px**；
     - 高清感知无损压缩（JPEG 质量 85~90，单张体积控制在 **400KB ~ 700KB，平均约 500KB**）；
     - 剥离无用 EXIF 隐私元数据；
  3. 覆盖写入 `records/{person}/{year}/...`，并同步核验/更新对应的 JSONL 记录（修正可能因旧图模糊而产生的推断或缺失标记）。
- **判定既有旧图已更优（旧图清晰完整，新图模糊或有裁切）**：
  - **坚决保留既有原件**，忽略新图，严禁以劣换优；
  - 在汇报中向用户说明保留原图的具体理由（如“既有单据文字更锐利且无反光，已为您继续保留既有原件”）。
- **判定两批单据页面互补（如旧图为 p1，新图包含 p2）**：
  - 增量补齐缺页（保存为 `-p2.jpg`），新页面同样必须经过 2400px 统一压缩流水线落盘。
- **用户透明汇报**：
  - 归档完成后的汇报中，必须清晰列出重复单据的比对决策结果（【高清置换并统一压缩】/【保留既有更优原件】/【增量补齐缺页】）。
